# 📚 Study Time Tracker

**Study Time Tracker** is a Python-based console application designed to help students record, manage, and monitor their study sessions.

The application allows users to track study time, set daily study goals, view study reports, search sessions, and manage their study records.

---

## ✨ Features

- ⏱️ Start a Live Study Session
- 📝 Add Study Sessions Manually
- 📋 View All Study Sessions
- 📊 View Subject-wise Study Summary
- 📅 Generate Today's Study Report
- 🎯 Set Daily Study Goals
- 🔍 Search Study Sessions
- 🗑️ Delete Study Sessions
- 💾 Save Study Data to a JSON File
- 🆔 Automatic Session ID Generation
- 📆 Automatic Date Tracking
- 🖥️ Simple Console-Based User Interface

## 📌 Main Features Explained

### 1. Start a Live Study Session

Users can enter a subject name and start a live study session.

After finishing their study, the session duration is recorded and added to the study tracker.

---

### 2. Add Session Manually

Users can manually enter:

- Subject name
- Study duration in minutes
- Optional notes

This feature is useful when a user wants to record a study session that was completed earlier.

---

### 3. View All Sessions

Users can view all recorded study sessions in a structured format.

Each session contains:

- Session ID
- Subject
- Duration
- Date
- Notes

---

### 4. Subject-wise Summary
